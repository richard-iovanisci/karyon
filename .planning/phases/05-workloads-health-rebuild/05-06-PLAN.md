<objective>
Run the final live destructive proof for Phase 5. This plan does not modify
source files. It proves that the strict rebuild chain works on the target dev
box with warm CUDA cache, finishes in under 20 minutes, and ends with
`task health-check` green.

Per BLOCKER #3 from checker round 1, `task rebuild` runs EXACTLY ONCE in this
plan (Task 2). Task 3 then runs the live state-checker bats
(`phase5-02-live.bats`) which reads `/tmp/karyon-rebuild.log` and checks
post-rebuild cluster state — it does NOT re-execute `task rebuild` itself.
This eliminates the previous double-rebuild that consumed ~40 minutes and
destroyed clusters between runs.

Per HIGH-1 and HIGH-3 from cross-AI Codex review (2026-04-28, revision round
2), the human-verify checkpoint in Task 1 has been UPDATED to make the Git
visibility precondition explicit AND to surface the kube-context pin contract.
The Phase 5 deploy-examples script now fails fast if the working tree is dirty
or HEAD != origin/main (HIGH-3), so the user must commit + push BEFORE running
`task rebuild` or the deploy step will exit nonzero. The rebuild script now
runs `kubectl config use-context k3d-hub-flux` between create-clusters and
bootstrap-flux (HIGH-1), eliminating a silent failure mode.
</objective>

The command must complete successfully. `scripts/rebuild.sh` writes the
following to `/tmp/karyon-rebuild.log` (per Plan 05-05 Task 2 contract):
- ordered step markers `>>> step destroy`, `>>> step create-clusters`,
  `>>> step bootstrap-flux`, `>>> step register-spokes`,
  `>>> step deploy-examples`, `>>> step health-check`
- (HIGH-1) the kube-context pin marker `>>> pin context k3d-hub-flux`
  appearing between `>>> step create-clusters` and `>>> step bootstrap-flux`
- a final line `rebuild elapsed seconds: N`

Do NOT re-run `task rebuild` to satisfy the verify block. The verify block
parses the log written by THIS single run.

If the final health is green but elapsed seconds exceed 1200, keep the failure;
do not override the hard SLO.
  </action>
  <verify>
    <automated>test -f /tmp/karyon-rebuild.log && grep -E '^rebuild elapsed seconds: [0-9]+' /tmp/karyon-rebuild.log | awk '{print $4}' | tail -1 | awk '$1<=1200{exit 0} $1>1200{exit 1}' && for s in destroy create-clusters bootstrap-flux register-spokes deploy-examples health-check; do grep -F ">>> step ${s}" /tmp/karyon-rebuild.log >/dev/null || exit 1; done && for pair in 'destroy:create-clusters' 'create-clusters:bootstrap-flux' 'bootstrap-flux:register-spokes' 'register-spokes:deploy-examples' 'deploy-examples:health-check'; do prev="${pair%%:*}"; next="${pair##*:}"; pl=$(grep -nF ">>> step ${prev}" /tmp/karyon-rebuild.log | head -1 | cut -d: -f1); nl=$(grep -nF ">>> step ${next}" /tmp/karyon-rebuild.log | head -1 | cut -d: -f1); [ "$pl" -lt "$nl" ] || exit 1; done && pin_line=$(grep -nF '>>> pin context k3d-hub-flux' /tmp/karyon-rebuild.log | head -1 | cut -d: -f1) && cc_line=$(grep -nF '>>> step create-clusters' /tmp/karyon-rebuild.log | head -1 | cut -d: -f1) && bf_line=$(grep -nF '>>> step bootstrap-flux' /tmp/karyon-rebuild.log | head -1 | cut -d: -f1) && [ "$cc_line" -lt "$pin_line" ] && [ "$pin_line" -lt "$bf_line" ]</automated>
  </verify>
