<threat_model>
**ASVS Level:** 1
**Block on:** high

- **T-05-09 Health-check mutation:** A mutating health check can hide the system
  state it is supposed to verify. Mitigation: script must not contain `kubectl
  apply`, `kubectl delete`, `k3d cluster stop`, or `k3d cluster start`.
- **T-05-10 Misleading DNS status:** Continuing after stale DNS can produce noisy
  downstream failures. Mitigation: DNS gate fails fast with `Fix: task fix-dns`.
- **T-05-11 Wrong-cluster proof:** Checking only spoke resources can miss Flux
  reconciliation failures. Mitigation: hub-side Flux Kustomization Ready checks
  are mandatory before direct workload checks.
</threat_model>

  <action>
Create executable `scripts/health-check.sh` with ordered sections exactly:

1. `Clusters and nodes`
   - Assert k3d clusters `hub-flux`, `spoke-ml`, and `spoke-apps` exist.
   - Assert `kubectl --context k3d-<cluster> wait --for=condition=Ready node
     --all --timeout=60s` for each cluster.
2. `Flux controllers`
   - Assert all Flux deployments Available on hub.
   - Run `flux --context k3d-hub-flux check`.
3. `Spoke Kustomizations`
   - Require hub-side `spoke-ml` and `spoke-apps` Kustomizations Ready=True.
4. `Hub DNS probe`
   - Run an in-hub pod DNS probe resolving `k3d-spoke-ml-server-0` and
     `k3d-spoke-apps-server-0`.
   - On failure, call `fail` with text containing `Fix: task fix-dns`.
5. `GPU capacity`
   - Assert `kubectl --context k3d-spoke-ml get nodes -o
     jsonpath='{.items[*].status.capacity.nvidia\.com/gpu}'` returns a numeric
     value greater than 0.
6. `TLS SANs`
   - Reuse the Phase 2 openssl pattern to assert each spoke API cert includes
     `DNS:k3d-<spoke>-server-0`.
7. `Workload proofs`
   - Assert podinfo Deployment Available=True on `k3d-spoke-apps` namespace
     `podinfo`.
   - Assert `job/nvidia-smi` Complete=True on `k3d-spoke-ml` namespace
     `gpu-smoke`.
   - Assert `kubectl --context k3d-spoke-ml -n gpu-smoke logs job/nvidia-smi`
     contains `NVIDIA-SMI`.

Do not include `kubectl apply`, `kubectl delete`, `k3d cluster stop`, or `k3d
cluster start` in this script.
