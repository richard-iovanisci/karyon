<objective>
Resolve the Phase 8 G-04 BLOCKER that has been preventing Flux reconciliation of the capsule POC since 2026-04-29. Two root causes are fixed:

1. **Missing capsule-system namespace on hub-flux** -- kustomize-controller fails with "namespaces capsule-system not found" when applying HelmRelease CRs because the namespace does not exist on hub. Adding an explicit Namespace resource to the kustomize build output creates it before the HelmRelease CRs are applied.

2. **D-11-01 PostBuild patch misplaced on Kustomization instead of HelmRelease** -- The RBAC extension for the capsule-proxy Role was placed as a `spec.patches` block on the outer Kustomization CR (`capsule.yaml`). Kustomization `spec.patches` only modify kustomize-build output (raw YAML files in the path). The Role is rendered by helm-controller from the Helm chart, so kustomize-controller never sees it. The correct Flux mechanism is `spec.postRenderers` on the HelmRelease, which applies Kustomize-style patches to helm-rendered chart output.

Purpose: Unblocks Flux reconciliation so poc-capsule Ready=True, capsule-proxy reinstalls via Flux, and the 11/12 negative-RBAC tests that were RED due to G-04 cascade can go GREEN.
Output: 5 file changes (1 new, 4 modified) + Flux reconcile verification checkpoint.
</objective>
