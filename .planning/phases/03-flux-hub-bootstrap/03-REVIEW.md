## Critical Issues

### CR-01: BLOCKER - Bootstrap fails after a successful first `flux bootstrap`

**File:** `scripts/bootstrap-flux.sh:189`
**Issue:** The script expects `${REPO_ROOT}/clusters/hub-flux/flux-system/kustomization.yaml` to exist locally immediately after `flux bootstrap github`, then exits if it is missing. Flux's GitHub bootstrap writes through a temporary Git working directory and pushes the manifests to GitHub; it does not guarantee that this local checkout is updated. In the current workspace, `clusters/hub-flux/flux-system/kustomization.yaml` is absent, so the first real bootstrap can succeed remotely and in-cluster, then this script fails in Section 5 with `expected ... missing`. That leaves the user with a partially completed bootstrap and no patch-surface marker applied locally or remotely.

Flux reference: https://fluxcd.io/flux/installation/bootstrap/github/ and source path `cmd/flux/bootstrap_github.go` in https://github.com/fluxcd/flux2, where the command creates a `flux-bootstrap-*` temporary working dir for the Git client.

**Fix:** Do not assume the local checkout contains files generated by Flux. Either sync the bootstrapped branch before Section 5, or move the marker application into the same remote Git workflow. If syncing locally, guard dirty worktrees before pulling:

```bash
if [[ ! -f "${KUST_FILE}" ]]; then
  if ! git -C "${REPO_ROOT}" diff --quiet || ! git -C "${REPO_ROOT}" diff --cached --quiet; then
    fail "bootstrap manifests were pushed to GitHub, but this checkout has local changes.
     Fix: commit/stash local changes, run: git -C ${REPO_ROOT} pull --ff-only origin main, then rerun scripts/bootstrap-flux.sh"
    exit 1
  fi
  git -C "${REPO_ROOT}" pull --ff-only origin main
fi
```

### CR-02: BLOCKER - `.env` is executed as shell code

**File:** `scripts/bootstrap-flux.sh:113`
**Issue:** `source "${REPO_ROOT}/.env"` executes arbitrary shell syntax from a gitignored secrets file. Preflight only checks for non-empty `GITHUB_OWNER`, `GITHUB_REPO`, and `GITHUB_TOKEN` with `grep`; it does not validate that `.env` is safe to execute. A malformed or copied `.env` containing command substitution or shell statements will run code before the token is passed to Flux.

**Fix:** Parse only the three expected keys as data and export them without sourcing the file:

```bash
load_env_key() {
  local key="$1" val
  val="$(grep -E "^${key}=" "${REPO_ROOT}/.env" | tail -n1 | cut -d= -f2-)"
  if [[ -z "${val}" ]]; then
    fail "${key} is missing or empty in .env"
    exit 1
  fi
  printf -v "${key}" '%s' "${val}"
  export "${key}"
}

load_env_key GITHUB_OWNER
load_env_key GITHUB_REPO
load_env_key GITHUB_TOKEN
```

## Warnings

### WR-01: WARNING - Gitleaks hook check reads the caller's working directory

**File:** `scripts/bootstrap-flux.sh:61`
**Issue:** The advisory checks `.git/hooks/pre-commit` relative to the process working directory, while the rest of the script resolves `${REPO_ROOT}`. Running the script from any directory other than the repo root can warn based on the wrong repository, or miss the actual repo hook entirely.

**Fix:** Anchor the hook path to `${REPO_ROOT}`:

```bash
hook="${REPO_ROOT}/.git/hooks/pre-commit"
if [[ -f "${hook}" ]] && grep -qF gitleaks "${hook}"; then
  pass "gitleaks pre-commit hook present"
else
  warn "gitleaks pre-commit hook not detected ..."
fi
```

### WR-02: WARNING - Predictable `/tmp` log path is unsafe

**File:** `scripts/bootstrap-flux.sh:42`
**Issue:** `PREFLIGHT_LOG="/tmp/preflight-$$.log"` is predictable and is opened with shell redirection. That creates an avoidable symlink/clobber risk and can leave host/environment details in a world-readable location depending on the user's umask.

**Fix:** Use `mktemp`, remove the log on success, and intentionally keep it only on failure:

```bash
PREFLIGHT_LOG="$(mktemp -t karyon-preflight.XXXXXX.log)"
if ! bash "${SCRIPT_DIR}/preflight.sh" > "${PREFLIGHT_LOG}" 2>&1; then
  fail "preflight has blockers - run scripts/preflight.sh and fix before bootstrapping flux.
     Log: ${PREFLIGHT_LOG}"
  exit 1
fi
rm -f "${PREFLIGHT_LOG}"
```
