## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.env` (gitignored secrets file) → `scripts/bootstrap-flux.sh` process | Untrusted *as code*: a malformed or malicious `.env` (typo, copy-paste from elsewhere, accidental shell statements) could inject behavior if sourced. Trusted *as data* for the three named keys only. |
| Local git worktree → `git pull --ff-only origin main` | The pull mutates the local working tree. If a developer has unrelated uncommitted changes under `${FLUX_PATH}/`, the sync could clobber them. Pull is fast-forward only — no merge, no rebase. |
| `flux bootstrap github` (subprocess) → process environment | The exported `GITHUB_TOKEN` flows into the flux subprocess via environ. Not on argv. Visible only to the flux process and its children, not to other users via `ps`. |
