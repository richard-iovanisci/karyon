**Script structure:**

```bash
#!/usr/bin/env bash
# scripts/install-nvidia-container-toolkit.sh
# Idempotent NVIDIA container toolkit installer for WSL2 Ubuntu 24.04.
# Installs nvidia-container-toolkit, configures Docker runtime integration.
# NOTE: Does NOT set default-runtime in daemon.json — install-docker.sh handles that.
#
# Prerequisites: Docker Engine must be installed (run install-docker.sh first).
# Usage:  bash scripts/install-nvidia-container-toolkit.sh
# Safe to re-run — skips steps already done.

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
# shellcheck source=lib/preflight-lib.sh
source "${SCRIPT_DIR}/lib/preflight-lib.sh"

NVIDIA_CONTAINER_TOOLKIT_VERSION="1.19.0-1"
```

**Section 1: NVIDIA apt keyring**
Guard: `[[ -f /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg ]]`
Action (from RESEARCH.md §Ref-3 — exact commands):
```bash
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey \
  | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg

curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list \
  | sed 's#deb https://#deb \[signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg\] https://#g' \
  | sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

sudo apt-get update -q
```
Log: `info "already done, skipping: NVIDIA apt keyring + repo"` / `pass "installing: NVIDIA apt keyring and repo"`

**Section 2: nvidia-container-toolkit packages**

  nvidia-container-toolkit="${NVIDIA_CONTAINER_TOOLKIT_VERSION}" \

  libnvidia-container-tools="${NVIDIA_CONTAINER_TOOLKIT_VERSION}" \

```

Guard: `docker info 2>/dev/null | grep -qi "Runtimes:.*nvidia"`
Pre-check: If docker is not reachable, fail with message "Docker daemon not reachable — run install-docker.sh first":

  pass "installing: nvidia-ctk runtime configure --runtime=docker"

fi
```

| nvidia.github.io → local keyring | GPG key fetched from NVIDIA's CDN and written to /usr/share/keyrings/ |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Elevation of Privilege | sudo commands in nvidia toolkit script | mitigate | All sudo calls use hard-coded commands; no user-controlled variables flow into sudo arguments; shellcheck enforces quoting |
| T-03-02 | Tampering | NVIDIA apt keyring fetch (nvidia.github.io) | accept | Official NVIDIA CDN; GPG dearmor writes to /usr/share/keyrings/; package signatures validated by apt; lab-only environment |
| T-03-03 | Elevation of Privilege | nvidia-ctk writes to /etc/docker/daemon.json | mitigate | Guard checks Runtimes:.*nvidia before calling nvidia-ctk; script documents what nvidia-ctk writes (runtimes key only, not default-runtime); reviewed via shellcheck |
</threat_model>
