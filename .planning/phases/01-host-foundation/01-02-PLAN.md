**Script structure (implement all sections below in order):**

#!/usr/bin/env bash
# scripts/install-docker.sh
# Idempotent Docker Engine installer for WSL2 Ubuntu 24.04.
# Installs docker-ce, configures daemon.json, adds user to docker group,
# and installs the hwclock-resume.service unit for clock-skew fixes.

**Section 2: Docker GPG key**

**Section 3: Docker apt repository**
Guard: `[[ -f /etc/apt/sources.list.d/docker.sources ]]`
Action (from RESEARCH.md §Ref-4 — exact .sources format for Ubuntu 24.04):
```bash

Types: deb

Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF
sudo apt-get update -q
```

**Section 6: daemon.json — default-runtime + dns** (jq-merge strategy, D-05, RESEARCH.md §Ref-4):
```bash
section "daemon.json (default-runtime + dns)"
DAEMON_JSON=/etc/docker/daemon.json
DESIRED_DNS='["1.1.1.1","8.8.8.8"]'
DESIRED_RUNTIME="nvidia"

if [[ -f "$DAEMON_JSON" ]] && \
   sudo jq -e '."default-runtime" == "nvidia"' "$DAEMON_JSON" >/dev/null 2>&1 && \
   sudo jq -e '.dns | length > 0' "$DAEMON_JSON" >/dev/null 2>&1; then
  info "already done, skipping: daemon.json default-runtime + dns"
else
  [[ ! -f "$DAEMON_JSON" ]] && echo '{}' | sudo tee "$DAEMON_JSON" > /dev/null
  current=$(sudo cat "$DAEMON_JSON")
  merged=$(echo "$current" | jq \
    --arg dr "$DESIRED_RUNTIME" \
    --argjson dns "$DESIRED_DNS" \
    '. + {"default-runtime": $dr, "dns": $dns}')
  echo "$merged" | sudo tee "$DAEMON_JSON" > /dev/null
  sudo systemctl restart docker
  pass "installing: daemon.json default-runtime=nvidia + dns=[1.1.1.1,8.8.8.8]"
fi
```

**Section 7: hwclock-resume.service** (D-08, from RESEARCH.md §Ref-8):
```bash
section "hwclock-resume.service (clock-skew fix)"
UNIT_SRC="${SCRIPT_DIR}/../config/hwclock-resume.service"
UNIT_DEST=/etc/systemd/system/hwclock-resume.service

if ! [[ -f "$UNIT_SRC" ]]; then
  fail "config/hwclock-resume.service not found at ${UNIT_SRC} — run from repo root or check Plan 01 output"
  exit 1
fi

if systemctl is-enabled hwclock-resume.service >/dev/null 2>&1; then
  info "already done, skipping: hwclock-resume.service"
else
  sudo cp "$UNIT_SRC" "$UNIT_DEST"
  sudo systemctl daemon-reload
  sudo systemctl enable hwclock-resume.service
  pass "installing: hwclock-resume.service (WSL2 clock-skew fix on resume)"
fi
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Script → sudo | install-docker.sh runs multiple sudo commands; must not accept user input that flows into sudo calls |
| apt keyserver → local keyring | GPG key downloaded from download.docker.com/linux/ubuntu/gpg and written to /etc/apt/keyrings/ |
| daemon.json → Docker daemon | jq-merge writes to /etc/docker/daemon.json with sudo; Docker daemon reads on restart |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Elevation of Privilege | sudo commands in install-docker.sh | mitigate | Each sudo call is to a fixed, hard-coded command with no user-controlled arguments; no `sudo $VAR` patterns; shellcheck enforces no quoting issues |
| T-02-02 | Tampering | Docker GPG key fetch (curl to download.docker.com) | accept | Official Docker domain; GPG signature chain validates packages post-install; lab-only environment — MITM risk accepted |
| T-02-03 | Tampering | NVIDIA apt repo signing key (Plan 03) | accept | Same rationale as T-02-02; official NVIDIA domain |
| T-02-04 | Elevation of Privilege | docker group membership | mitigate | D-05 documented: docker group = root-equivalent; intentional for lab; documented in script comment that user must explicitly re-login — no silent activation |
| T-02-05 | Tampering | /etc/docker/daemon.json jq-merge | mitigate | Guard checks both keys before writing; jq merge (not overwrite) preserves existing keys; sudo required for write |
| T-02-06 | Elevation of Privilege | hwclock-resume.service runs as root | accept | Scope is /sbin/hwclock --hctosys only; reads RTC, sets system clock; no network, no file modification; WSL2 lab environment |
</threat_model>
