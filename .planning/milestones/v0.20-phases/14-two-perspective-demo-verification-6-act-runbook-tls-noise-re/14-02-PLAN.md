## Drift remediation policy (Rule-3 deviation allowance)

If any demo-* bats fails RED in this plan, the failure modes are bounded:
- **Drift A: Phase 13 primitive missing or mutated** → STOP. File a BLOCKER summary entry. Do NOT modify Phase 13 artifacts to chase GREEN; Plan 14-02 is verification-only. Escalate to milestone-owner for Phase 13 gap-fix plan.
- **Drift B: capsule-proxy LIST filter wiring drift** (e.g., tenant-charlie home-namespace ownership not registered — Phase 10/11 D-11-02 inheritance) → STOP. Same escalation.
- **Drift C: bats assertion bug** (e.g., regex mismatch on a kubectl version difference) → ALLOWED to adjust the bats file with explicit `fix(14-02):` commit subject + SUMMARY note explaining the adjustment. The bats file is Wave-0 falsifier; minor regex / status-code adjustments to match live reality are within scope.
- **Drift D: nondeterministic test flake** (intermittent timeout / connection error) → re-run up to 2x. Persistent flake → degrade to documented carry-forward.

Anything beyond Drift C scope is OUT of Plan 14-02.
